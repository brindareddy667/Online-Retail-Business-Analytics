# Online Retail Business Analytics

An end-to-end data analytics project that analyzes online retail transaction data to identify **sales trends, customer behavior, product performance, and business insights** using Python and Power BI.

## 📌 Project Overview

This project focuses on analyzing an online retail dataset containing transactional sales information. The data was cleaned, transformed, explored, and visualized to understand business performance and identify meaningful patterns.

The project combines **Python-based data analysis** with an interactive **Power BI dashboard** to turn raw transactional data into clear and actionable business insights.

## 🎯 Objectives

* Clean and prepare raw retail transaction data for analysis.
* Perform exploratory data analysis (EDA) to identify important trends and patterns.
* Analyze sales and revenue performance.
* Understand customer purchasing behavior.
* Identify top-performing products.
* Analyze sales trends over time.
* Create an interactive Power BI dashboard for business reporting.
* Present key findings through KPIs and visualizations.
